# Real-Time Chat Application

## About the Project

A web-based chat interface developed using HTML, CSS, and JavaScript. The application provides a simple and interactive messaging experience with user details, last seen status, incoming and outgoing messages, and message timestamps.

## Features

* User profile image and name in the message header
* Last seen status
* Incoming and outgoing messages
* Sender avatars and message timestamps
* Message input field and send button
* Simple and user-friendly interface

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server, or open it directly in a web browser.

## Purpose

This project was developed to practice frontend web development and create an interactive chat interface.
